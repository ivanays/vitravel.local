О проекте

Я более 20 лет проработал мастером по ремонту обуви. Для учета рабочих процессов построил собственную систему управления содержимым (CMS). Это веб-приложение написано на стеке HTML/CSS/PHP7/MySQL8. За основу я взял книгу Кевина Янга (Kevin Yank) "PHP и MySQL. От новичка к профессионалу" (2013г). Получился прототип. Его можно найти по ссылке: https://github.com/ivanays/adminka9.ru. В файле README.md есть информация по развёртыванию и тестированию приложения. Это был мой первый опыт (2019г).


Быстрый запуск

1. Загрузите и установите локальный сервер OSPanel для ос Windows (https://ospanel.io/download/). 
2. В разделе "Настройки" откройте вкладку "Модули". Сделайте следующие настройки сервера: HTTP - "Apache_2.4-PHP_7.2-7.4"; PHP - "PHP_7.2"; MySQL/MariaDB - "MySQL-8.0-Win10". Сохраните изменения.
3. Перейдите в "phpmyadmin" по ссылке: http://127.0.0.1/openserver/phpmyadmin/. Авторизация: пользователь - "root"; пароль оставляем не заполненным. Выполните вход. 
4. Создайте с помощью панели phpmyadmin базу данных "adminka2", пользователя "adminka2", пароль "adminka2", host "localhost". Настройте привелегии пользователя. База данных должна иметь тип "InnoDB" и сравнение "utf8mb3_general_ci".
5. Импортируйте с помощью панели "phpmyadmin" базу данных из файла /mysql/adminka2.sql. 
6. Содержимое репозитория adminka9.ru (https://github.com/ivanays/adminka9.ru) скопируйте в корневую папку adminra9.ru локального хостинга OSPanel.
7. Запустите локальный сервер от имени администратора. Выберите "adminka9.ru" во вкладе "Мои проекты" админ-панели сервера OSPanel. Откроется стартовая страница (https://adminka9.ru/) с формой для входа в админку.
8. Авторизуйтесь как superadmin: телефон 000 000 00 00; пароль "nometro23". После чего попадёте в админ-панель с полным функционалом. Для moderator (телефон 111 111 11 11; пароль "nometro23") доступно только создание, редактирование, удаление счетов.
9. После авторизации, возможно, антивирус посчитает ресурс опасным и выдаст предупреждение. Согласитесь на вход или внесите исключения в настройках антивирусной программы.


Как это работает 

1. Во вкладке "Администраторы админки" настроивается доступ к админ-панели. Здесь можно администатора добавлять, редактировать, удалять. Профиль состоит: номер - ххх ххх хх хх (10 знаков); пароль - сохраняется в зашифрованном виде;  роль - superadmin (полный доступ), moderator (частичный доступ), anonim (нет доступа). Все данные сохраняются в таблице "admin" базы данных "adminka2".
2. Вкладки "Управление операторами связи", "Управление списком регионов", "Управление списком статусов", "Управление списком изделий", "Управление списком полов", "Управление списком материалов", "Управление списком цветов", "Управление списком ед. измерения" оперируют данными, описывающие те или иные свойства, и являются простыми. Они, в свою очередь, используются в описании составных свойств, данные которых редактируются в соответствующих вкладках: "Управление клиентами", "Услуги", "Счета". 
3. Все данные основанные на простых свойствах хранятся в файлах (*.ini). Здесь записывыются, читаются, обновляются и удаляются записи. Информация о клиентах, услугах и счетах доступна в соответствующих таблицах базы данных.
4. Вкладка "Управление клиентами" нужна для поиска клинентов в базе данных по различнам критериям. Здесь также есть ссылка на форму регистрации новых клиентов с подбором необходимых свойств для наиболее полного описания. При регистрации клиента также автоматически создаётся его группа. В неё можно добавлять клиентов, которые могут связаться с ним, если клиент стал недоступен. Эта возможность реализуется при переходе по ссылке "ДОБАВИТЬ В ГРУППУ". Она находится после описания каждого клиента в разделе "РЕЗУЛЬТАТ ПОИСКА" на странице "Управление клиентами" и "ДАННЫЕ КЛИЕНТА №*" на страницах "ОФОРМЛЕНИЕ ЗАКАЗА", "РЕДАКТИРОВАНИЕ ЗАКАЗА".
5. Вкладка "Управление услугами" отображает все услуги, состоящие из различных параметров (вид услуги, единица измерения, материал, цена, комментарии). Принцип - составные из простых. Услуги можно добавлять, редактировать и удалять в корзину (архив). По необходимости их можно восстановить или удалить безвозвратно. 
6. На вкладке "Счета" сходится вся логика приложения. Она ускоряет процесс оформления и редактирования заказа. Можно тут же скорректировать нужные данные, расчитать общую сумму всех оказанных услуг с учётом дополнительных скидок и доплат. Большой перечень критериев поиска. Есть возможнсть сделать первичный анализ, правда пока без графиков.
